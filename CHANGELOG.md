# Documentation changelog

This changelog tracks this public guide. It is not the deployment history of the hosted ShareOfAsk service.

## docs-v1.0.0 (November 3, 2026)

First tagged release of the connection and usage guide. This version identifies the documentation, independently of the hosted service and MCP Apps UI versions.

- Added a direct Free Scan entry point for new users and a separate connection path for existing customers.
- Clarified MCP availability across Free Scan, Starter, Growth and Enterprise, with current access limits.
- Added a compact overview of the 16 core tools, the five view launchers and copyable Codex setup.
- Added CC BY 4.0 licensing for documentation and illustrations, MIT licensing for scripts and code/configuration examples, and explicit brand guidance.
- Made the first-result prompt suitable for a workspace with a single saved measurement.
- Simplified punctuation across the guide.

## November 2, 2026: Public integration guide

- Added hosted MCP connection guides and dated client verification notes.
- Added nine workflows for agencies, marketing teams and content/SEO teams.
- Added copyable prompts, a tool reference, permissions guidance and data interpretation notes.
- Added five Figma-authored illustrations using fictional data and the compact ShareOfAsk MCP Apps design.
- Added troubleshooting, contribution guidance and documentation link checks.

The illustrated product interface is MCP Apps UI 1.2.0. See [Compatibility](docs/clients/compatibility.md) for the scope and limitations of client verification.
