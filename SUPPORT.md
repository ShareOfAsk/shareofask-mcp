# Get help

Start with [Troubleshooting](docs/troubleshooting.md) for connection, permissions, missing data or panel issues.

| What you need | Where to go |
| --- | --- |
| A correction to this guide or an example workflow | [Open a documentation issue](https://github.com/ShareOfAsk/shareofask-mcp/issues/new/choose). |
| Help with your account, workspace, plan or private data | Email [hello@shareofask.com](mailto:hello@shareofask.com). |
| A security concern | Follow [SECURITY.md](SECURITY.md) and contact us privately. |

Public issues are visible to everyone. Describe the client, approximate time, steps taken and a redacted error. Do not post credentials, authorization codes or private customer data.
