# Reporting a security concern

Send a private report to [hello@shareofask.com](mailto:hello@shareofask.com) with the subject **ShareOfAsk MCP security report**. This is ShareOfAsk's published contact address. Do not open a public issue with exploit details, credentials or another customer's information.

Include the affected feature, approximate time, client/version, expected behavior and a minimal redacted description of what happened. Share only the evidence needed to understand the issue; never send a live access token or password.

If you suspect a connection has unwanted access, revoke it in ShareOfAsk's **Account Settings → Integrations**. See [Permissions](docs/permissions.md) for how connection access works.

This document provides a private reporting route. It does not authorize access to other people's accounts or data, and it does not establish a bounty or response-time commitment.
