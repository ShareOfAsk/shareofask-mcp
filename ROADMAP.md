# Documentation roadmap

This roadmap covers the public integration guide. It does not promise future product features or client availability.

## Available

- Hosted-service connection guide and tool reference.
- Agency, marketing and content/SEO playbooks.
- Prompt library, permissions and methodology notes.
- Illustrated workflows and troubleshooting.
- A Free Scan starting point and guidance on MCP access across current plans.
- A compact core-tool overview and copyable Codex setup in the README.
- Reusable documentation and illustrations under CC BY 4.0, with MIT-licensed code/configuration examples and scripts.
- Versioned documentation releases, starting with `docs-v1.0.0`.

## Next documentation improvements

- Record verified Claude connection and interactive-view results when that testing is completed.
- Extend ChatGPT verification to standard CSP enforcement and investigate first-open rendering failures.
- Add verified setup examples for further OAuth-compatible MCP clients based on actual testing.
- Expand the playbooks using questions and feedback from real users, with all public examples anonymized or fictional.

Registry and app-directory submissions are separate from this repository's publication. Current listings or approvals will be linked only after they exist.
